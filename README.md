This is a vault for Obsidian, containing notes for **AP statistics**.  
  
To check notes on your own device, follow steps below.  
# Install Git via Command Line Tool
Git is a tool that helps you get up-to-date contents from Internet.

**For macOS:**
Open Terminal.app and run ``xcode-select --install``.

**For Windows:**
Open PowerShell(Administrator) through Start menu and run ``winget install Git.Git``.

# Clone this Repository
By cloning this repository, you may access to notes locally.

In the same terminal window, run ``git clone https://github.com/SakisakaSuzune/Statistics``.
(If you are using a proxy, copy and run the "shell command" from your proxy app **first**.)
(If you want to clone the repo into a specific folder, type ``cd `` and drag that folder into the window then run it **first**.)

# Download Obsidian
Download Obsidian at [obsidian.md/download](https://obsidian.md/download) and open it.  
Choose "Open Local Vault" and select the folder named "Statistics" at the place you cloned it (your user folder is the default).
