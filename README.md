This is a vault for Obsidian, containing notes for **AP statistics**.  
  
To check notes on your own device, follow steps below.  
# Download GitHub Desktop
Download GitHub Desktop at [desktop.github.com](https://desktop.github.com) and open it.
# Clone this Repository
Choose "Add▾" and "Clone Repository..."  
Choose **URL**".  
Enter "SakisakaSuzune/Statistics" in to the URL box.  
Choose a place to store this repository as the "Local Path".  
Clone.
# Download Obsidian
Download Obsidian at [obsidian.md/download](https://obsidian.md/download) and open it.  
Choose "Open Local Vault" and select the folder named "Statistics" at the place you cloned it.
