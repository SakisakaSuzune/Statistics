# Definition
A statistic measure that describes how do the data vary from the mean, in other words, how scattered are the data in a distribution.

# Explanation
The xxx in a randomly selected sample would typically differ from the mean by about *standard deviation* units. 

# What's the difference between 𝜎 and Sx?
$\sigma$ is used to describe a population. It is a parameter.
$\sigma = \sqrt{ \frac{1}{N} {\sum_{i=1}^{N} (X_{i}-\mu)^2} }$

$S_{x}$ is used to describe a sample. It is a statistic. 
$S_{x} = \sqrt{ \frac{1}{n-1} \sum_{i=1}^n (X_{i} - \bar{x})^2 }$
