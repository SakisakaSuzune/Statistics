[English](README.md)  
这是一个用于Obsidian的知识库，包含**AP统计学**的相关笔记。

要在自己的设备上查看笔记，请按以下步骤操作。

# 通过命令行工具安装Git
Git是一款帮助您从互联网获取最新内容的工具。

**对于macOS用户：**
打开终端应用并运行``xcode-select --install``。

**对于Windows用户：**
通过开始菜单打开PowerShell（管理员模式）并运行``winget install Git.Git``。

# 克隆此仓库
通过克隆此仓库，您可以在本地访问笔记内容。

在同一个终端窗口中运行``git clone https://github.com/SakisakaSuzune/Statistics``。  
（若使用代理，请先复制并运行代理应用中的“终端命令”）  
（如需将仓库克隆到特定文件夹，请先输入``cd ``并将目标文件夹拖入窗口后执行该操作）

# 下载Obsidian
请通过[obsidian.md/download](https://obsidian.md/download)下载Obsidian并打开程序。
选择“打开本地仓库”，找到克隆生成的“Statistics”文件夹（默认为用户文件夹）。

# 更新笔记
笔记内容会不定期更新。
在Obsidian中安装Git插件后点击“pull”即可同步更新。
